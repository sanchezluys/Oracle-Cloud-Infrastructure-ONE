### Crear Cuenta OCI Free Tier

```mermaid
flowchart TD
    %% Version 1.0: sanchezluys 2024
    inicio((**Inicio**))-->
    crearCuenta[Crear Cuenta Free Tier 30 dias con crédito] 
    --> accederOracle[**Acceder a Oracle Cloud**]
    click accederOracle "https://www.oracle.com/cloud/free/" "Ir a Oracle Cloud Free Tier"
    accederOracle --> registrarDatos[Se registra con datos básicos: _pais_, _nombre_, _apellido_, _correo_]
    registrarDatos --> verificarCorreo[El correo debe ser verificado]
    verificarCorreo --> correoLlego{¿El correo de validación llegó?}
    correoLlego -->|**SI** | validarCuenta[**Validar Cuenta**: Clic en el enlace de validación]
    correoLlego -->|**NO** | reintentarRegistro[**Reintentar Registro**]
    reintentarRegistro --> accederOracle
    validarCuenta --> seguirRegistro[Seguir al 2do registro, _clave_, _nombre-empresa_, **region-principal**, _aceptar-condiciones_]

    aceptaTDC --> |NO| reintentarTDC[Reintentar]-->formTDC

    -->cuentaActiva[Cuenta creada con éxito]
```

### Comandos desde la consola o terminal de OCI

| Item | Comando | Uso |
| --------- | --------- | --------- |
|     1      | uname -m          |  muestra el SO, por ejemplo: aarch64, linux         |
|   2        |   oci --version        |  muestra la versión de OCI  ejm: 3.49.2       |

## Creando una instancia

- Es un computador - servidor virtual

```mermaid
flowchart TD
 %% Version 1.0: sanchezluys 2024, crear grupo
    inicio((**Inicio**))-->
    ingresaOci[Ingresar a cuenta OCI con el usuario de desarrollo] 
    --> redes[**Acceder a Recursos Informáticos -> Instancias**]
    --> inst_1l[**Validar que se esta en el compartimiento de desarrollo**]
    --> inst_2[**Crear Instancia**, nombre ejemplo vm-1, compartimiento, ]
    --> img_1[**Seleccionar la imagen** importante seleccionar una que siempre sea gratis, como SO oracle 8, o ubuntu, linux etc]
    --> shape_1[**Seleccionar el shape** se refiere al hardware, se recomienda Amd, o Ampere que sea siempre gratis, con ram y cpu habilitados para la cuenta free tier]
    --> ssh_1[**Agregar la llave publica ssh** se puede crear desde la consola o la creada anteriormente, ls -a, cd .ssh, cat llave.pub ]
    --> crear_1[**Crear Instancia** el proceso se inicia con el aprovisionamiento, puede demorar unos minutos, el usuario es por defecto **opc** y la direccion ip publica aparece en la instancia, para conectarse es necesario usar la llave con **ssh opc@ip_publica -i cloudshellkey**]
```
